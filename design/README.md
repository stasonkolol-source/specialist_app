# Дизайн «Сосед» — утверждённый эталон

Утверждён владельцем 2026-09-27. Холст с живым прототипом: https://claude.ai/artifact/AWVeVGWKQZQ8cAAyCjgnEH

## Что здесь

| Путь | Что это |
|---|---|
| `ui.css` | Токены (светлая и тёмная тема) и компоненты дизайн-системы — основа фронтенда (шаги 0.16a–0.19c плана) |
| `SPEC.md` | Правила отрисовки экранов: каркас, компоненты, иконки, демо-данные, продуктовые правила на экранах |
| `project/*.dc.html` | 72 файла: `Main.dc.html` (дизайн-система) и 71 артборд — экраны S01–S58, бот B1–B2, тёмная тема D03/D13/D30 |
| `project/canvas.json` | Раскладка артбордов на холсте |
| `MANIFEST.sha256` | Контрольные суммы; проверка — `shasum -a 256 -c design/MANIFEST.sha256` из корня репозитория |

## Правила

- **Эталон не правим.** Изменение дизайна — новая версия на холсте, согласованная с владельцем, затем новая копия сюда с новым манифестом.
- Экраны в коде сверяются с артбордами (`make design-compare`, шаг 0.19c плана).

## Как открыть локально

- Файлы `.dc.html` — формат холста Design: `support.js` отдаёт хост холста, в этой папке его нет.
- `ui.css` в артбордах подключён адресом `/_blob/…` хранилища холста.
- Шрифты Onest и Unbounded грузятся с Google Fonts.

Для рендера вне холста нужны подмена этих путей и сеть (шаг 0.19c). Смотреть и кликать прототип удобнее на холсте по ссылке выше.
