## 1. Скелет артборда (обязателен дословно)

```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<title>S13 · Лента заявок</title>
<script src="./support.js"></script>
<link rel="stylesheet" href="/_blob/7759b923ae90366bc47b73b4d5476dfa">
</head>
<body>
<x-dc>
<helmet>
<link href="https://fonts.googleapis.com/css2?family=Onest:wght@400;500;600;700&amp;family=Unbounded:wght@500;600&amp;display=swap" rel="stylesheet">
<style>body{margin:0;background:#E9EBEE}</style>
</helmet>
<div class="scr" style="width: 390px; height: 844px">
  …экран…
</div>
</x-dc>
<script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":390,"height":844}}'>
class Component extends DCLogic {
  renderVals() { return {}; }
}
</script>
</body>
</html>
```

Правила, нарушение которых ломает отрисовку:
- **Строки в `<head>`.** Строка `support.js` — ровно такая. Ссылка на `ui.css` (`/_blob/7759…`) — сразу после неё.
- **Корневой `div.scr`** получает inline `width` и `height`, равные размеру артборда (обычно 390×844; высокие экраны — по таблице в §6). Тот же размер — в `$preview`.
- **Разметка.** Все элементы закрыты, все атрибуты в кавычках, `&` в URL записывается как `&amp;`. Никаких `innerHTML`, эмодзи и `<iframe>`.
- **Семантика.** Кнопки — `<button type="button">`, переходы — `<a href="…">`, поля — `<input>` и `<textarea>` с `<label>`. У кнопок-иконок обязателен `aria-label`.
- **Иконки** — только inline SVG из §3, класс `ic`, атрибут `aria-hidden="true"`.
- **Стили.** Используем классы из `ui.css` (§2); inline `style` — только для раскладки: отступы, ширина, gap, позиция.
- **Текст** — на русском, кроме примеров сербского контента. Только реальные фразы интерфейса, без lorem ipsum.
- **Числа.** Разряды отделяются `&nbsp;`: `5&nbsp;000 RSD`. Кавычки «ёлочки», тире «—», знак «≈».
- **Переходы.** BackButton — `<a class="tgh-btn" href="<родитель>.dc.html">`; вкладки таббара — `<a class="tab" href="…">`; главные CTA — `<a class="mbtn" href="следующий.dc.html">` (у `<a>` класс кнопки, внутри `<a>` не должно быть `<button>`).

- 16 — контейнеры: карточка, группа, плитка, баннер, вариант `opt`, тост, карта;
- 12 — поля (и поиск), кнопки, фото и блоки внутри карточки (ответ на отзыв), «+» таббара, системная заметка чата;
- 10 и 9 — производные: `btn sm` и `row-ic`; сегмент `seg` = 12 − 3 (отступ дорожки);
- 8 — бейджи и скелетон по умолчанию;
- 6 — галочки и маленькие плашки (скрытый контакт в чате);
- полное скругление — чипы, композер, аватары, точки;
- 20 — верх шторки.

**Тени** тонированы цветом текста `rgba(17,20,24,…)`, не чистым чёрным.

Сброс внутри `.scr`: у `h1–h4`, `p`, `ul`, `ol` нет внешних отступов, у списков нет маркеров — inline `margin: 0` не нужен. `a.card`, `a.tile`, `a.row`, `a.chip`, `a.btn`, `a.mbtn`, `a.tab` сами получают правильный цвет текста. Сегменты-ссылки: `<nav class="seg"><a class="on" href="…">…</a><a href="…">…</a></nav>`, для кнопок — `<div class="seg"><button class="on" type="button">…</button>…</div>`.

## 5. Решения продукта, которые экраны обязаны отражать

- **Лимит откликов.** Не больше 5 на заявку, счётчик «откликов 3 из 5» и «осталось 2 места», метка «откликнулся первым».
- **Контакты** до договорённости скрыты. В чате телефоны и ссылки маскируются с подсказкой «контакты откроются после договорённости». «Поделиться контактом» появляется только после сделки `agreed` (S54).
- **Адрес** заявки виден только выбранному исполнителю. Публично — район и примерная точка.
- **Отзывы в MVP** оставляет только клиент по завершённой сделке, публикуются сразу. «Отзывы до платформы» — отдельной вкладкой, в рейтинг не входят. «Новый специалист», если отзывов меньше 3.
- **Бейджи** называют факт: «Телефон подтверждён» (добровольный). KYC «Личность подтверждена» — v1, на экранах MVP не показывать, кроме S39, где он помечен «скоро».
- **Предоплата.** Предупреждение «Не вносите предоплату незнакомым исполнителям» — на карточке специалиста, в сделке и в чате.
- **Языки** интерфейса в MVP: Русский, Srpski (latinica), Српски (ћирилица). English помечен «скоро».
- **Экраны v1** (S07, S40, S41, S50, S51): в заголовке артборда пометка «(v1)», внутри — обычный дизайн. На экранах MVP нет цен в Stars и слова «Pro»; исключение — S40.
- **Подработка:** «задачи», «заказы», «доп. доход». Не «работа» и не «вакансии».
- **Прокрутка.** Каждый экран — одно состояние прокрутки; не помещается — сокращайте, не сжимайте шрифт. Минимум 13 px для второстепенного текста и 15 px для основного.
