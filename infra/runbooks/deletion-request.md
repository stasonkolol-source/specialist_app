# Запрос на удаление аккаунта через поддержку

Право на удаление — ZZPL ст. 30, срок ответа — **30 дней** (ст. 21). Удалить аккаунт можно в
приложении (ARCHITECTURE §7.10, DEVELOPMENT_PLAN 2.12a). Поддержка помогает пользователю
запустить удаление и объясняет, что останется.

## 1. Принять запрос

1. Запрос приходит в поддержку (@sosedi_support_rse, S47) или в бот. Записать дату получения,
   Telegram id отправителя и номер обращения; срок — дата + 30 дней.
2. Удалить можно только свой аккаунт: запрос должен прийти **с того же Telegram-аккаунта**.

## 2. Запустить удаление

Удаление запускает сам пользователь — так подтверждается, что это он:

1. Mini App → «Профиль» (S31) → «Удалить аккаунт» → экран S45 → кнопка удаления.
2. Удаление наступает через **7 дней**; до этого его можно отменить на S31, там же видна дата.

В ответе пользователю: что удалится, что останется (ниже) и дата удаления.

Пользователь не может войти (потерял доступ к Telegram) — подтвердить, что это он, нельзя.
По такому запросу аккаунт не удаляем, эскалация владельцу.

## 3. Что происходит дальше

Через 7 дней ежечасная задача `identity.process_deletions`:

- меняет имя на «Удалённый пользователь», удаляет способы входа, телефон, сессии и блокировки;
- рассылает `UserDeleted`, и модули удаляют своё: профиль специалиста и портфолио, прайс,
  файлы, уведомления и каналы, атрибуцию, текст сообщений; заявки снимаются с публикации;
- записывает хэши Telegram ID и телефона на **12 месяцев** (антифрод: повторная регистрация —
  сигнал риска); потом их удаляет ночная `platform.retention_sweep`.

В бэкапах данные живут ещё до 30 дней.

**Legal hold.** Пока о пользователе открыт кейс модерации или идёт спор по его сделке, удаление
ждёт решения: запрос остаётся, задача проверяет его каждый час. Пользователю — «удалим после
решения жалобы», как на S45.

С тем же псевдонимным id остаются решения модерации, жалобы и акцепты правил (3–5 лет по
исковой давности) и обезличенные сделки для статистики. Отклики, заявки и переписку удаляет
`platform.retention_sweep` по срокам хранения: 24 месяца после закрытия заявки и 12 месяцев
после последнего сообщения (§7.10).

PostHog: удаление персоны по `UserDeleted` появится вместе с аналитикой на проде (K32). До
этого прод не шлёт событий в PostHog — удалять там нечего.

## 4. Проверить и закрыть

Через 7 дней (или после решения кейса):

```sql
SELECT status FROM identity.users WHERE id = '<user_id>';                        -- deleted
SELECT completed_at FROM identity.deletion_requests WHERE user_id = '<user_id>'; -- не NULL
```

Сообщить пользователю, что аккаунт удалён, и закрыть обращение с датой ответа. Если перед
удалением пользователь просит копию данных — [data-export.md](data-export.md).
