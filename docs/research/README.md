# Исследования

Каждый отчёт готовил отдельный исследовательский агент со своим фокусом. Правила подготовки:
- факты проверены по первоисточникам на **2026-09-26**;
- у каждого утверждения есть ссылка на источник;
- всё неподтверждённое помечено **[Допущение]**.

Противоречия между отчётами разрешены при сведении и отражены в [ARCHITECTURE.md](../ARCHITECTURE.md) и [ADR](../adr/README.md).

> **Ограничение.** В середине исследования закончилась общая квота веб-поиска сессии. Поэтому часть фактов в отчётах 01, 03–06 проверена прямым чтением официальных страниц и реестров пакетов (PyPI, npm), а не поиском. Такие места отмечены в самих отчётах.
