# Сиды пилотной зоны (DEVELOPMENT_PLAN 0.27)

Черновики для правок владельца (K21): пилот — Нови-Сад (Q18 по умолчанию), пять категорий
первой волны из PRODUCT.md (Q19). Утверждение — в шагах 1.3a (гео) и 1.3b (каталог), там же
загрузка в БД.

| Файл | Что внутри |
|---|---|
| `geo/novi-sad.geojson` | Город и 27 районов: 23 квартала Нови-Сада и пригороды Петроварадин, Сремска-Каменица, Ветерник, Футог. Полигоны из OpenStreetMap (ODbL, атрибуция в файле), упрощены до ~5 м. «Народные» названия — в `aliases` |
| `catalog/taxonomy.yaml` | 5 категорий, 13 подкатегорий, теги, синонимы на ru / sr / en, `risk_level`, ориентиры цен (research/01 §4.2) |
| `catalog/queries.yaml` | Регрессионный набор «запрос → категория» для поиска (расширяется в 4.3b) |
| `moderation/content_rules.yaml` | Словарь модерации (2.4): стоп-слова ru, sr, uk, en, регулярки и домены с действием (`block`, `flag`, `shadow`) и категорией. Черновик ассистента — владелец дополняет реальными словами (K28) |
| `moderation/rule_examples.yaml` | Набор «текст → действие и категории» для словаря; `seeds-validate` падает, если правка словаря ломает пример |

Проверка: `make seeds-validate` (или `cd backend && uv run python -m app.entrypoints.cli seeds-validate`).

Загрузка в БД: `make seed` — гео, каталог и словарь модерации, идемпотентно: повтор ничего не меняет, правка файла
обновляет только изменённые города, районы и категории. Ориентиры цен из `taxonomy.yaml` (целые
динары) хранятся в пара, названия sr-Latn генерируются из sr-Cyrl, синонимы попадают в словарь
поиска `catalog.search_terms` вместе с названиями категорий и тегов на всех языках.
То, что ведёт админка (2.7b), сид задаёт только новой строке: включён ли город, район, категория
и тег, порядок городов и категорий, иконку категории; название, поправленное в админке, сид тоже
не трогает. Новое значение в файле действует для новой строки, существующую правят в админке.

Демо-специалисты для dev и stage (2.8c): `make seed-demo` — 60 профилей по 13 листьям каталога:
прайс, районы Нови-Сада, фото работ (заглушки проходят обычную загрузку и обработку media), у
части — «доступен сегодня»; и 20 клиентов с заявками, откликами, сделками и отзывами. Создаются
use cases и сразу одобряются, без автопроверки, аналитики и уведомлений. Повтор ничего не меняет,
на проде команда не работает. `make seed-demo SCALE=lab` — 50 000 профилей без фото, объём
лаборатории (research/07 §2.7); идёт часами, прогресс — каждые 500. Демо-пользователи узнаются по
Telegram ID от 5·10¹⁵: у настоящих он не длиннее 52 бит. Тексты —
`app/entrypoints/_seed_demo_content.py`.

Язык — `DEMO_LANG` (`--lang`): по умолчанию `ru` — все русскоязычные жители Нови-Сада (имена,
тексты, заявки, отклики и отзывы по-русски); `sr` — все по-сербски латиницей, `mixed` — каждый
второй. Повтор не переписывает уже засеянных: сменить язык или обновить демо-людей — `make
seed-demo REPLACE=1` (`--replace`, только dev). Он сначала удаляет всех прежних демо-людей обычным
удалением аккаунта, но сразу, без grace-периода (их профили, прайс, портфолио, заявки, отклики,
чаты, сделки и отзывы удаляет воркер по UserDeleted, как у людей), затем сеет новых с теми же
Telegram ID. Демо-человек с открытым кейсом модерации ждёт решения и остаётся. Настоящие
пользователи не затронуты; в их прошлых сделках и чатах с демо-людьми собеседник — «Удалённый
пользователь». На стенде: `make cli ARGS='seed-demo --replace'`.

Обновить полигоны из OSM: `cd backend && uv run python seeds/tools/osm_districts.py novi-sad`.
Список районов, slug и «народные» названия — в `seeds/tools/osm_districts.py` (`NOVI_SAD`).
Русские названия районов — черновая транслитерация: поправьте в `ru=` или в файле.

Словарь модерации: слова сравниваются по скелету текста — «кокаин», «kokain» и «к0каин» одно
и то же, `*` в конце — любое окончание. Правило, которого больше нет в файле, `make seed`
выключает; правила, заведённые в админке, сид не трогает. Как писать правила — в шапке
`moderation/content_rules.yaml`.

Что проверить владельцу:
- словарь модерации: добавить реальные слова и примеры из очередей (K28), особенно слова,
  которые нельзя блокировать сразу (у них есть безобидный смысл в услугах);
- районы: все ли нужны, не хватает ли (Ново насеље = Бистрица, Центар = Стари град);
- русские и «народные» названия;
- категории, подкатегории, синонимы и ориентиры цен в Нови-Саде.
